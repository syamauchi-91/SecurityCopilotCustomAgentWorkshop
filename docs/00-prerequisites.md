# Lab 0: 事前準備

**所要時間:** 開催前 30 分  
**ゴール:** 当日に権限やライセンスで止まらないように、必要な準備を先に整えておく

> [!NOTE]
> この Lab は主に「準備の確認」です。権限などは自分だけでは揃えられないこともあるので、難しい項目は遠慮なく管理者にお願いしましょう。

## 0-1. アカウントを確認する

次のアカウントを用意します。ブラウザーで複数の組織（テナント）を使い分けている場合は、演習で使うテナントをはっきり選んでおくと安心です。

- 組織から GitHub Copilot Enterprise を割り当てられた GitHub アカウント
- Microsoft Security Copilot を利用できる職場または学校アカウント
- Microsoft Sentinel/Defender の演習データを読み取れるアカウント

## 0-2. 管理者へ依頼する

開催前に管理者へ次を確認してください。

| 確認項目 | 最低条件 | 確認結果 |
|---|---|---|
| GitHub Copilot | 組織から対象ユーザーへ Enterprise ライセンスを割り当て済み | [ ] |
| Security Copilot | 利用可能な容量がプロビジョニング済み | [ ] |
| カスタムプラグイン | Owner が Owners/Contributors に追加・管理を許可済み | [ ] |
| Sentinel MCP | 少なくとも Security Reader ロール | [ ] |
| Sentinel data lake | データ探索ツールを使う場合はオンボード済み | [ ] |
| Defender | Advanced Hunting の演習データへアクセス可能 | [ ] |
| Logic Apps | 応用演習を行う場合は作成・実行・履歴確認が可能 | [ ] |

> [!CAUTION]
> Security Copilot のロールは Azure RBAC や Microsoft Entra ロールとは別です。Security Copilot 内の権限と、データソース側の権限の両方が必要です。

## 0-3. 演習データを確認する

この教材は組織ごとにテーブルや列が異なることを前提にしています。講師は次を用意してください。

1. 過去 24 時間に読み取り可能なサインインイベントがあることを確認します。
2. 演習用の Sentinel インシデント番号を 1 件控えます。
3. 実データを投影する場合は、受講者が閲覧してよいテナントとワークスペースに限定します。
4. データがない場合は、演習を YAML 生成と構文レビューまでに切り替えます。

## 0-4. API 演習の方針を選ぶ

VirusTotal 演習は外部サービスへ値を送信します。次のどちらかを選びます。

- **デモモード:** ダミーキーでマニフェスト登録まで行い、実 API は呼ばない
- **実行モード:** 組織で承認された演習用 VirusTotal API キーを Security Copilot の設定画面にだけ入力する

API キーを YAML、Copilot Chat、GitHub、画面ショットへ含めてはいけません。

## チェックポイント

- [ ] GitHub Copilot Chat を利用できる
- [ ] Security Copilot ポータルへサインインできる
- [ ] Security Copilot でカスタムプラグインを追加できる
- [ ] Sentinel/Defender の演習データに読み取りアクセスできる
- [ ] VirusTotal 演習をデモモードか実行モードのどちらで行うか決めた

満たせない項目がある場合は、当日までに管理者へ依頼するか、該当 Lab を講師デモへ切り替えます。
